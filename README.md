# 時間錯覚ゲーム（Temporal Illusion Game）

科学館での展示用に制作した、**「時間の感じ方」を体験するゲーム**です。
ルールの違う2つのミニゲームを遊び、「どちらのゲームが長く感じたか」を答えてもらいます。
同じ長さの時間でも、画面の忙しさや出来事の多さによって感じ方が変わる、という時間知覚の錯覚を体験できます。

## ゲームの流れ

1. コントローラーを持ってスタート（右のボタンで画面送り、左スティックで左右移動）
2. **ゲーム①**：たくさん、速く落ちてくるコインを取り、矢をよける
3. **ゲーム②**：少なく、ゆっくり落ちてくるコインを取り、矢をよける
4. 2回のゲームの合計スコアと、その日の最高スコアを表示
5. 「長かったのはどっち？」を選択（左右ボタン）
6. 正解を発表

### 仕掛け

2つのゲームのうち、片方は **20秒**、もう片方は **15秒** です。どちらが長いかは毎回ランダムに決まります。

| パターン | ゲーム①（多い・速い） | ゲーム②（少ない・遅い） |
|---|---|---|
| 0 | 20秒（`8a lot long`） | 15秒（`10a few short`） |
| 1 | 15秒（`8a lot short`） | 20秒（`10a few long`） |

ゲーム②では、オブジェクトの出現間隔・落下速度・プレイヤーの移動速度がゲーム①の約1/3になります。

### スコア

| | コイン | 矢 |
|---|---|---|
| ゲーム① | +1000 | −500 |
| ゲーム② | +2000 | −1000 |

各ゲームの終了時に、得点に応じて `best` / `normal` / `bad` の画面が表示されます。

展示向けに、30秒間操作がないとタイトル画面（`1slide`）に戻るようにしています。

## 動作環境

- Unity **2022.3.22f1**
- TextMesh Pro
- ゲームパッド（ジョイスティック）またはキーボード・マウス
  - 移動：左スティック / ←→キー
  - 決定：ボタン0 / マウス左クリック

## 開き方

1. このリポジトリをクローンします（動画・音声は Git LFS で管理しています）
   ```
   git lfs install
   git clone <このリポジトリのURL>
   ```
2. Unity Hub で「Add」からこのフォルダを追加し、Unity 2022.3.22f1 で開きます
3. `Assets/Scenes/1slide.unity` を開いて再生します

## 主なファイル

| ファイル | 内容 |
|---|---|
| `Assets/Scenes/1slide`〜`15slide` | 説明・結果表示などのスライド画面 |
| `Assets/Scenes/8a lot long / short` | ゲーム①（20秒版 / 15秒版） |
| `Assets/Scenes/10a few long / short` | ゲーム②（20秒版 / 15秒版） |
| `Assets/Scenes/best / normal / bad` | 各ゲームの結果画面 |
| `GameDirector.cs` / `GameDirector2.cs` | 20秒版 / 15秒版のタイマーと得点管理 |
| `PatarnObject.cs` | どちらのゲームを長くするかをランダムに決定 |
| `ItemGenerator.cs` | コインと矢の生成 |
| `player.cs` | プレイヤーの移動と当たり判定 |
| `YourScore.cs` / `HighScore.cs` | 合計スコアと最高スコアの表示 |
| `answerscript.cs` | 正解（①/②）の表示 |
| `move*.cs` / `scorescript.cs` | 画面遷移と無操作時のリセット |
